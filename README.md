# RIFT · Разлом

**Гравитация — теперь оружие.** Мощная гравитационная перчатка с тремя способностями: подними отряд врагов, швырни его в стену, пронеси́сь сквозь строй и схлопни собственную сингулярность. Никаких новых боссов, арен и обязательных босс-файтов.

**Minecraft Java 1.21.1 · Fabric Loader 0.16.14+ · Fabric API для 1.21.1 · Java 21.**

## Установка

1. Установи **Minecraft Java Edition 1.21.1** и [Fabric Loader](https://fabricmc.net/use/installer/).
2. Положи `rift-1.0.0.jar` и [Fabric API **для 1.21.1**](https://modrinth.com/mod/fabric-api/versions?g=1.21.1) в `.minecraft/mods/`. Подходит Fabric API `0.116.0+1.21.1` или новее для этой версии игры; сборка проверяется с `0.116.18+1.21.1`.
3. Для мультиплеера установи мод и Fabric API **на сервер и каждому игроку**. На чистой ванили, Forge, NeoForge и Bedrock мод не работает.

Готовый устанавливаемый файл после сборки: **`build/libs/rift-1.0.0.jar`**. Не устанавливай `-sources.jar`. Мир перед установкой новых модов лучше сохранить отдельно.

## Управление

Возьми перчатку в основную или вторую руку. Появится HUD с энергией, выбранным режимом и тремя отдельными перезарядками.

| Действие | Управление |
| --- | --- |
| Применить выбранную способность | **ПКМ** |
| Удерживать Вектор → бросить | **Удерживай ПКМ → отпусти** |
| Следующий режим | **V** (переназначается в настройках) |
| Сменить режим без отдельной клавиши | **Красться + ПКМ**; отпусти ПКМ перед следующим переключением |
| Краткая справка и рецепт в игре | **`/rift`** |

### 01 / Вектор

**20 энергии · перезарядка 2,5 с.** Захватывает до **6 врагов** в конусе перед тобой на расстоянии до **14 блоков**. Держи ПКМ: цели поднимутся и последуют за прицелом, а лежащая рядом добыча притянется к тебе. Отпусти — враги полетят вперёд с **18 базового урона**. Столкновение создаёт волну радиусом **3 блока** с **12 урона**. Максимальное удержание — **3 секунды**, затем автоматический бросок.

### 02 / Импульс

**30 энергии · перезарядка 2 с.** Быстрый рывок в направлении взгляда, в том числе вверх. Противники на траектории и в завершающей волне радиусом **5 блоков** получают **22 базового урона** — каждый не более одного попадания за рывок. Перчатка не телепортирует сквозь стены. Защита от падения действует до приземления, максимум **6 секунд**. Рывок недоступен в транспорте и при полёте на элитрах.

### 03 / Сингулярность

**80 энергии · перезарядка 12 с.** Создаёт гравитационную воронку в точке прицела на расстоянии до **24 блоков**. **3,5 секунды** она стягивает врагов и предметы из радиуса **9 блоков**, наносит периодический урон и схлопывается с **40 базового урона** и сильным отбрасыванием. Золотые орбиты, бирюзовое кольцо, тёмное ядро — эффект видят и остальные игроки.

Урон подчиняется обычной броне и неуязвимости Minecraft. Все числа выше — настройки по умолчанию. Энергия общая для всех перчаток одного игрока: **100 единиц**, восстановление **10/с** после паузы **1,5 с**; во время удержания целей восстановление приостановлено. Выход из игры не обнуляет затраты и перезарядки; офлайн они не отсчитываются.

## Получение без боссов

Перчатка есть в творческой вкладке **«Сражение»**, а также выдаётся командой с правами на читы:

```mcfunction
/give @s rift:rift_gauntlet
```

Рецепт на верстаке:

| | | |
| :---: | :---: | :---: |
| Осколок эха | Осколок аметиста | Осколок эха |
| Алмаз | Незеритовый слиток | Алмаз |
| Плачущий обсидиан | Жемчуг Эндера | Плачущий обсидиан |

Получи осколок эха, чтобы открыть рецепт в книге. Звезда Незера, яйцо дракона и убийство боссов не нужны. Перчатка не изнашивается и не сгорает в лаве.

## Безопасность мира и мультиплеер

- Ни одна способность не меняет блоки, не поджигает мир и не создаёт настоящие разрушающие взрывы.
- Игроки, приручённые питомцы, жители, големы, стойки для брони, именные мобы и ванильные боссы исключены из целей. Обычные мирные животные тоже защищены по умолчанию.
- Захват, притяжение и волны проверяют видимость: сквозь сплошные стены урон не проходит. Сущности перемещаются обычной физикой с коллизиями, без телепортации.
- Энергия, выбор целей, ограничения, урон и перезарядки рассчитываются сервером. Две перчатки не дают два запаса энергии; два игрока не могут одновременно захватить одного моба.
- Активные захваты и воронки отменяются при смерти, выходе и смене измерения; воронка также отменяется, если убрать перчатку из обеих рук. Мод не меняет исходные флаги ИИ и гравитации мобов.
- Есть полная русская и английская локализация. HUD скрывается без перчатки, в меню и по F1.

Это сильное оружие, а не система защиты регионов: предметы на земле могут притягиваться независимо от того, кто их выбросил. Для публичного сервера учитывай это при выдаче перчаток.

## Настройки сервера

При первом запуске создаётся `config/rift.json`. Изменения применяются после перезапуска сервера/игры:

```json
{
  "damageMultiplier": 1.0,
  "energyRegenPerSecond": 10.0,
  "maxHeldMobs": 6,
  "affectPassiveMobs": false
}
```

Границы: множитель урона `0.1…10`, восстановление `0…100` в секунду, захват `1…8` целей. При `affectPassiveMobs: true` можно воздействовать на обычных мирных мобов, но защита игроков, приручённых питомцев, жителей, големов, именных мобов и боссов остаётся. Ошибочный JSON не затирается: мод пишет предупреждение и использует безопасные значения.

Административная команда **`/rift recharge`** полностью восстанавливает энергию и перезарядки; требуется уровень прав **2**. Для обычной игры она не нужна.

## Сборка и проверки

Установи **JDK 21**. Gradle Wrapper включён в репозиторий, отдельно устанавливать Gradle не нужно.

```bash
./gradlew build             # JUnit + клиентская/серверная компиляция + устанавливаемый JAR
./gradlew runGametest       # интеграционные тесты внутри настоящего Minecraft-сервера
./gradlew runClient         # клиент для ручной проверки
```

Windows: `gradlew.bat build` / `gradlew.bat runGametest`. Для игры требуется графическая среда с OpenGL; сборка и GameTests работают без дисплея. Серверные GameTests не запрашивают учётную запись Minecraft.

JUnit проверяет расход энергии, защиту от спама, независимые перезарядки, задержку восстановления, режимы, повреждённые сохранения и конфигурацию. GameTests проверяют настоящие сущности, защищённые цели, стены, бросок, рывок, схлопывание/отмену воронки, NBT-сохранение, сетевой кодек и рецепт. Отчёты: `build/reports/tests/test/index.html` и `build/gametest-results.xml`.

Оригинальные пиксельные текстуры воспроизводятся командой `python3 tools/generate_assets.py` (нужен Pillow). Лицензия кода и авторских ассетов — **MIT**.
