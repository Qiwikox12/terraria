# ✦ LUMEN

**Медный резонатор — сканер, который слышит мир сквозь камень.**

Minecraft **1.21.1** · Fabric · Java 21

</div>

LUMEN добавляет один предмет — **Резонатор**. Это карманный сканер резонанса: он «прослушивает» пространство вокруг игрока и подсвечивает найденное **сквозь стены** аккуратным контуром. Ни боссов, ни новых сущностей, ни кастомной геометрии — только сканер, его режимы и немного тактической аккуратности.

## ⚡ Возможности

- **Три режима резонанса** — `R` переключает: **Руда → Тайники → Существа**.
- **Быстрое сканирование** — ПКМ: радиус 14 блоков, расход 30 заряда.
- **Глубокое сканирование** — Shift + ПКМ: радиус 22 блока, расход 60 заряда.
- **Автовосстановление заряда** — в покое резонатор копит энергию сам: полный бак за 25 секунд.
- **Подсветка сквозь стены** — контуры целей видны за камнем; до 96 целей одновременно, каждая живёт 9 секунд.
- **HUD-панель LUMEN** — заряд, число сигналов, расстояние до ближайшей цели, подсказки и индикатор остывания.
- **Серверный приоритет** — все проверки, цены и перезарядки выполняет сервер.
- **Данные, а не хардкод** — цели сканирования лежат в тегах, их легко расширять датапаком.
- **Достижения и статистика** — от «Первого импульса» до «Полного спектра».
- **Локализация** — английский и русский.

## 🎛 Режимы

| Режим | Что находит |
|---|---|
| **Руда** | Рудные блоки: все руды, древние обломки, растущий аметист и аметистовые кластеры |
| **Тайники** | Сундуки, бочки, эндер-сундуки, спавнеры, испытательные спавнеры, хранилища, декоративные горшки, подозрительный песок и гравий |
| **Существа** | Живые цели вокруг игрока |

Наборы целей — теги `lumen:resonant_ores` и `lumen:resonant_caches`: сервер может дополнить или урезать их своим датапаком.

## 🧭 Управление

| Действие | Кнопка | Радиус | Стоимость |
|---|---|---|---|
| Сменить режим резонанса | `R` | — | — |
| Быстрое сканирование | `ПКМ` | 14 блоков | 30 заряда |
| Глубокое сканирование | `Shift + ПКМ` | 22 блока | 60 заряда |

После сканирования резонатор остывает: 4 секунды после быстрого, 10 — после глубокого.

## 🧪 Крафт

```
┌───┬───┬───┐
│ C │ A │ C │
├───┼───┼───┤
│ R │ E │ R │
├───┼───┼───┤
│   │ C │   │
└───┴───┴───┘
```

- `C` — **медный слиток**
- `A` — **аметистовый осколок**
- `R` — **красная пыль**
- `E` — **осколок эха** — его добывают в Древних городах, поэтому Резонатор — награда за вылазку в Глубокую тьму

## ⚙️ Конфигурация — `config/lumen.json`

| Параметр | По умолчанию | Описание |
|---|---|---|
| `range` | 14 | Радиус быстрого сканирования |
| `deepRange` | 22 | Радиус глубокого сканирования |
| `maxCharge` | 100 | Максимальный заряд |
| `scanCost` | 30 | Стоимость быстрого скана |
| `deepScanCost` | 60 | Стоимость глубокого скана |
| `rechargeTicks` | 5 | Тиков на +1 заряда в покое |
| `highlightTicks` | 180 | Время жизни подсветки (9 секунд) |
| `maxHighlights` | 96 | Максимум подсвеченных целей |
| `cooldownTicks` | 80 | Перезарядка быстрого скана (4 секунды) |
| `deepCooldownTicks` | 200 | Перезарядка глубокого скана (10 секунд) |

## 🛡 Честная игра

- Сканер не рентген: подсветка временная (9 секунд), ограничена по числу целей, оплачивается зарядом и перезарядкой.
- Логика сканирования **полностью серверная**: радиусы, цены, кулдауны и лимиты проверяет сервер, клиент лишь рисует результат.
- В мультиплеере действует **конфиг сервера** — клиент не может удешевить сканирование, поднять радиус или обойти остывание.

## 📦 Установка

| Требование | Версия |
|---|---|
| Minecraft | **1.21.1** |
| Fabric Loader | **≥ 0.16.9** |
| Fabric API | **≥ 0.116.18** |
| Java | **21** |

1. Установите Fabric Loader через установщик с [fabricmc.net](https://fabricmc.net/use/).
2. Скачайте **Fabric API** для 1.21.1 и положите в `.minecraft/mods`.
3. Положите туда же `lumen-1.0.0.jar`.
4. Запускайте игру с Java 21.

## 🔨 Сборка из исходников

```bash
./gradlew build
```

Готовый мод появится в `build/libs/lumen-1.0.0.jar`.

## 🩺 Если что-то не так

- **Мод не загружается** — проверьте Java 21 и совпадение версий Fabric Loader и Fabric API.
- **Нет текстуры или перевода** — нажмите `F3 + T`; если не помогло, перезапустите игру.
- **Рецепта нет в книге крафта** — он разблокируется, когда в инвентаре появляется любой из ингредиентов.
- **Сканер «молчит»** — проверьте заряд и остывание; цель может быть вне радиуса.
- **В мультиплеере что-то не так** — правила задаёт сервер: сверьтесь с `config/lumen.json` на его стороне.
