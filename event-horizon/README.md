# Event Horizon · Горизонт событий

**Управляй гравитацией, а не ещё одной полоской здоровья босса.**

Мод для **Minecraft Java Edition 1.21.1 · Fabric · Java 21**. Одна гравиперчатка, четыре сочетающиеся способности, собственные пиксельные текстуры, цветной HUD, пространственные эффекты и встроенное руководство на русском и английском. Новых боссов, арен с обязательными боями и разрушения блоков способностями нет.

## Установка

1. Установи [Fabric Loader](https://fabricmc.net/use/installer/) **0.16.14 или новее** для **Minecraft 1.21.1**.
2. Установи [Fabric API](https://modrinth.com/mod/fabric-api/versions?g=1.21.1) **0.116.18+1.21.1** (или более новый выпуск именно для 1.21.1).
3. Положи `event-horizon-1.0.0.jar` и Fabric API в `.minecraft/mods/`.
4. Запусти профиль Fabric. Мод нужен **и на сервере, и у каждого игрока**.

Это не Bedrock-мод, не плагин Paper и не сборка для Forge/NeoForge. Перед установкой любых модов сделай резервную копию мира. Здесь нет встроенных Minecraft/Fabric API: они устанавливаются отдельно.

## Попробовать сразу

В творческом режиме открой вкладку **«Горизонт событий»**. Либо с разрешением на команды:

```mcfunction
/eventhorizon kit
```

Команда выдаёт перчатку, 16 ячеек потока и руководство. На сервере она доступна операторам с уровнем прав 2+. В обычном выживании всё крафтится — боссовые трофеи не нужны.

| Управление | Действие |
| --- | --- |
| ПКМ с перчаткой | Применить выбранную способность |
| **R** | Следующий режим: притяжение → импульс → скачок → сингулярность |
| **V** | Открыть полевое руководство |
| ПКМ с ячейкой потока | Восстановить до 60 энергии; при полном заряде ячейка не тратится |
| ПКМ с руководством | Открыть тот же справочник |

R и V переназначаются в настройках управления. В руководстве работают стрелки, кнопки и прокрутка. Перчатка работает и во второй руке, если предмет в основной руке не перехватывает ПКМ.

## Четыре режима

Здоровье и урон ниже измерены в единицах: **2 единицы = 1 сердце**. Время указано для 20 серверных тиков в секунду.

| Режим | Действие | Энергия | Перезарядка |
| --- | --- | ---: | ---: |
| **Притяжение** | Выбери цель или поверхность до 18 блоков. Поле радиусом 6 блоков в течение 1,5 с собирает врагов и выпавшие предметы; само не наносит урон. | 16 | 2 с |
| **Импульс** | Круговая ударная волна радиусом 8 блоков. 10 базового урона и сильное отбрасывание. | 22 | 3 с |
| **Скачок** | Перемещение по направлению взгляда до 12 блоков. Ищет твёрдую безопасную опору, проверяет весь путь и габариты игрока. | 12 | 1,5 с |
| **Сингулярность** | Требует 3 резонанса. Четыре секунды стягивает врагов и предметы в радиусе 8 блоков, затем схлопывается: до 34,8 урона с уменьшением к краю поля. | 45 | 20 с |

### Резонанс — причина комбинировать

Первое успешное обычное применение даёт **1 резонанс**. Следующее применение **другого** режима в течение 8 секунд увеличивает его до 2, затем до 3. Каждое звено обновляет восьмисекундное окно. Повтор того же режима сбрасывает серию до 1; ожидание обнуляет её. Не обязательно использовать все три разных режима: притяжение → импульс → притяжение тоже считается.

Импульс получает **+15% урона за каждый уже накопленный заряд**. Сингулярность расходует все три заряда. Рабочая комбинация: **скачок к группе → притяжение → импульс → сингулярность**. Учитывай, что импульс разбрасывает цели: наведи сингулярность на их новое положение.

Запас — **100 энергии**, восстановление — **5 в секунду**, только пока перчатка в руке. Для длинных серий пригодятся ячейки. Между применениями есть общий интервал 0,4 с. Попытка без цели, энергии или безопасного места ничего не расходует. Творческий режим не отключает ресурсную механику.

## Крафты

Рецепты открываются в обычной книге рецептов при получении материалов.

**Гравитационное ядро**: `I` — железный слиток, `A` — осколок аметиста, `E` — эндер-жемчуг.

```text
I A I
A E A
I A I
```

**Гравитационная перчатка**: `C` — медный слиток, `I` — железный слиток, `G` — ядро, `D` — алмаз, `·` — пусто.

```text
C I C
I G I
D · I
```

**4 ячейки потока**: осколок аметиста + красная пыль + светокаменная пыль, без формы.

**Полевое руководство**: книга + осколок аметиста, без формы.

## Безопасность мира и мультиплеер

- По умолчанию способности воздействуют на враждебных мобов, а притяжение — также на предметы. Игроки и мирные животные не являются целями.
- Командные союзники, приручаемые питомцы, лошади, стойки для брони, дракон и иссушитель исключены. Защиту типов сущностей можно расширить тегом `eventhorizon:gravity_immune`.
- Стены блокируют область воздействия. Скачок не проходит сквозь стены, границу мира, жидкости, опасные блоки или незагруженные чанки; в пустоту он не отправляет.
- **Сами способности не меняют блоки.** Ванильные опасности, например самостоятельный взрыв крипера, по-прежнему подчиняются правилам мира.
- Сервер рассчитывает цели, стоимость, урон, комбо и перемещение. Клиент не присылает координаты или величину урона.
- Энергия, режим и таймеры сохраняются **на игрока**, а не на экземпляр предмета. Подмена перчатки, смена измерения и переподключение не сбрасывают перезарядку. Офлайн энергия не копится; таймеры идут только пока работает мир.
- Поля прекращаются при выходе, смерти или смене измерения владельца и не держат чанки загруженными. Одна активная сингулярность на игрока; максимум 32 одновременных поля на сервер.
- Эффекты используют локальные частицы по компактным серверным сообщениям, без пакета на каждую частицу. Учитывается ванильная настройка количества частиц; тряски камеры нет.

## Настройка сервера

При первом запуске создаётся `config/eventhorizon.json`. Изменения применяются после перезапуска сервера / игры.

```json
{
  "allowPlayerTargets": false,
  "affectPassiveMobs": false,
  "showParticles": true,
  "regenerationIntervalTicks": 4,
  "maxAffectedEntities": 48,
  "damageMultiplier": 1.0
}
```

Для PvP нужны одновременно `allowPlayerTargets: true` и включённое PvP сервера; защита союзников остаётся. Лимиты: восстановление 1–200 тиков, 1–128 целей на поле, множитель урона 0,1–10. Неверный JSON не ломает запуск: используются безопасные значения, исходный файл сохраняется для исправления, причина записывается в журнал.

## Сборка и проверки

Нужен **JDK 21**, не только JRE. Gradle устанавливается wrapper-скриптом автоматически; версия 8.12 и SHA-256 дистрибутива закреплены. При первой сборке нужен интернет для Maven и официальных ресурсов Minecraft.

```sh
cd event-horizon
./gradlew build
./gradlew runGametest
./gradlew runClient
```

На Windows используй `gradlew.bat`. Готовый мод: `build/libs/event-horizon-1.0.0.jar`; файл `-sources.jar` — исходники, **не устанавливай его вместо мода**.

- `build` запускает JUnit-тесты энергии, комбо, таймеров и сохранения состояния.
- `runGametest` проверяет игровую интеграцию в настоящем Minecraft-сервере; отчёт — `build/reports/gametest.xml`.
- Тестовый мод и GameTest-классы не входят в выпускаемый JAR.
- `runClient` запускает Minecraft в среде разработки. В Linux для графической проверки нужны OpenGL, дисплей (или Xvfb) и системные библиотеки LWJGL.
- Оригинальные текстуры воспроизводимо генерируются командой `python3 tools/generate_art.py`; внешних Python-зависимостей нет.

Не заявляется проверка совместимости со всеми модпаками. Сначала воспроизведи проблему только с Fabric API и Event Horizon. Исходники и оригинальные ресурсы — [MIT](LICENSE); Minecraft, его звуки и стандартные частицы принадлежат их правообладателям.
